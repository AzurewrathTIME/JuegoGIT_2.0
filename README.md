# 🐙 Proyecto de Práctica con Git y Python 🐍

¡Bienvenido! 👋 Este proyecto fue desarrollado como una **práctica de programación en Python y manejo del sistema de control de versiones Git**.

El objetivo principal del ejercicio no solamente fue crear un pequeño programa, sino también aprender a trabajar con **Git desde la terminal**, realizando diferentes cambios y registrándolos mediante commits. 💻🔀

---

## 🎯 Objetivo del proyecto

Este proyecto tiene como finalidad practicar:

* 🐍 Creación y ejecución de programas en Python.
* 🧩 Creación y utilización de funciones.
* ➕ Operaciones matemáticas básicas.
* 🌱 Uso de Git desde la terminal.
* 💾 Registro de cambios mediante **commits**.
* 📤 Subida y actualización del proyecto en GitHub.

La idea fue ir desarrollando el programa progresivamente y utilizar Git para llevar un historial de los cambios realizados.

---

## 🧮 Funcionalidades

El programa cuenta actualmente con dos operaciones matemáticas principales:

### ➕ Suma

La función `sumar()` recibe dos números y devuelve el resultado de su suma.

```python
def sumar(a, b):
    return a + b
```

### ➖ Resta

La función `restar()` recibe dos números y devuelve el resultado de su resta.

```python
def restar(a, b):
    return a - b
```

## 🌱 Trabajo con Git

Una parte fundamental de este proyecto fue utilizar **Git desde la terminal** para registrar el desarrollo paso a paso.

En lugar de realizar todos los cambios de una sola vez, se fueron haciendo modificaciones al proyecto y posteriormente se registraron mediante **commits**.

Un flujo de trabajo utilizado durante el proyecto fue:

```bash
git add .
git commit -m "Descripción del cambio"
git push
```

### 📌 Conceptos practicados

* 📁 Repositorio
* 🌿 Rama (`branch`)
* ➕ `git add`
* 💾 `git commit`
* 📤 `git push`
* 📥 `git pull`
* 📜 Historial de cambios
* 🐙 GitHub

---

## 🔄 Historial de desarrollo

El proyecto fue evolucionando mediante diferentes commits realizados desde la terminal.

Esto permitió mantener un **historial de modificaciones**, haciendo posible observar cómo fue avanzando el programa desde sus primeras versiones hasta la versión actual.

💡 Una de las ventajas principales de Git es que cada commit funciona como un punto de referencia dentro del desarrollo del proyecto.
